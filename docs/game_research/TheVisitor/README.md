# The Visitor (来訪者)

The user's brief (DECISIONS 2026-10-28, evening): a game set in Japan, mostly in one mid-sized apartment (two bedrooms,
one of them the guest room, a bathroom, the kitchen and living room in one). An old female friend and first crush comes
to visit, and things start to go weird. Little tasks in the manner of Chilla's Art; dialogue read by her mocapped face,
as in L.A. Noire; the player answering with an act and a thought. At least an hour, three endings, secrets that make
good Steam achievements.
