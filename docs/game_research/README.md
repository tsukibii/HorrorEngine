# Game research: before the writers' room

One folder per game, written before anything is charted or built. These are the user's three steps for a new game
(DECISIONS 2026-10-28, evening):

1. **Research**: real events, cases and stories to draw on, each with what it gives the game (`01_research.md`).
2. **The abstract**: the whole game in a few pages, pitched for the user's yes (`02_abstract.md`).
3. **The flow**, once the user approves the abstract: the game part by part as the writers' room's chart. Claude writes
   it as the chart's script (`/chart`, docs/WRITERS_ROOM.md §9), the user inspects it in the writers' room, and
   `/build-game` takes it to the director.

Nothing in a game's folder is a decision until the user says so; their answers go in docs/DECISIONS.md as usual.
