# Exports/interiors

The scene builder's **Export for Godot** writes each level here, a folder each: `<name>/<name>.glb` and its
`README.txt`. A set's level is named after the set; a game's `<game>_<level>`. See ../README.md.

`hotel_floor/` is ready-made and in git: tutorial v2's floor, so the tutorial can start in Godot (../README.md).
