# The prints library

Pictures for a garment's prints: a tee's front and back, a sleeve (docs/CLOTHING_PLAN.md item 6). In the Character
Studio a worn garment's *Fabric, pattern, print* has up to three prints, each text or a picture: a file of yours, or
one from here (*from the library…*). Drop your own PNG, JPG or WEBP here (transparent PNG for a print without a box
round it); the Studio lists everything in this folder.

The ones here are ours, made in code by `tools/character/tailor/make_prints.py` in the project's OFL fonts
(`tools/propgen/fonts/`, their licences beside them): varsity_tokyo, night_shift, sunset_summer, smiley, studio_badge,
staff, sakura.
