# The handwriting fonts (the `book` use: play.gd, book.gd)

The hands a book's pages are written in at run time (STORY_FORMAT: a book's `hand`), all under the SIL Open Font
Licence 1.1 (their texts in `licences/`; they ship with a game as they are, beside their licences, and are never sold
alone): `hand` Caveat (Impallari Type), `hand2` Indie Flower (Kimberly Geswein), `hand_jp` Yomogi (Satsuyako: Latin,
kana and JIS level 1 and 2 kanji), `pen_jp` Zen Kurenaido (Yoshimichi Ohira). `print` is the HUD's own font. The same
files are the prop generator's (`tools/propgen/fonts/`): a diary's pages baked with them match what the game writes.
